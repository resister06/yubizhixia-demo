# 御笔之下

正式定稿 v1.0.0 · 2026-11-08  
作者：赵芮、申圣杰、刘柏漪

古风政务剧情网页游戏，面向电脑端。使用原生 HTML、CSS、JavaScript，无第三方运行依赖，无须构建。

## 上传 GitHub

1. 解压发布压缩包，进入“御笔之下-正式定稿-v1.0.0”文件夹。
2. 将文件夹内的全部文件和 assets 文件夹上传到仓库根目录。不要只把 ZIP 上传到仓库；index.html 应直接位于仓库根目录。
3. 如需在线游玩：进入仓库 Settings → Pages，选择 Deploy from a branch，分支选择 main，目录选择 / (root)，保存。按 GitHub 的页面提示取得访问链接。
4. .nojekyll 已包含在包内。素材使用相对路径，可用于 GitHub Pages 的项目地址。

## 本地运行

安装 Node.js 后，在本文件所在目录执行：

```sh
npm start
```

浏览器打开 http://127.0.0.1:4173/ 。不需要 npm install。

语法检查：

```sh
npm run check
```

本地服务支持音视频正确 MIME 类型及 Range 分段加载。请通过 HTTP 服务打开游戏。

## 定稿内容

- 公主线开放，皇子线暂未开放；命名限1—4个汉字。
- 开场序言、伴读视频、路清河介绍与睡醒剧情。
- 修堤、流民、陆家商税地图事件；第一年跳年说明、第二年储君监国与殿外闻语。
- 六方势力地图、正式初始数值、财政/治理/军事机制、朝局分布说明与问号帮助。
- 顾家任官奏折与数值变化演示；正式版预告、金色粒子标题、两页结语。
- 春秋背景、天黑天亮转场、开场/日常/地图结尾配乐。
- 页面保留主要“继续”交互；右上小按钮显示“快进”，沿用继续动作，不跳过整道奏折；左侧卷轴图标用于剧情回看。
- 进度与选择保留在本次页面会话中，刷新后重新开始。

## 文件说明

- index.html、style.css：页面结构与界面样式。
- app.js：流程、交互、音乐与转场。
- story-data.js：剧情、奏折和选项。
- study.js：书房、政务、年份与选择界面。
- faction-state.js：势力与机制初值、选项结算。
- identity-effects.js、title-particles.js、rich-text.js：选人特效、片尾粒子与重点文字。
- assets/：图片、透明立绘、音乐及兼容版视频。
- server.mjs：本地静态与音视频预览服务。
- SHA256SUMS.txt：发布文件校验清单。

本包包含源码和运行素材，不包含对话记录、私人文档、临时脚本或核查截图。发布前请确认仓库可见性符合你的意愿。
